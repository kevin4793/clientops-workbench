# 客户到期工作台 · 银行理财经理版（ClientOps）

## 背景
现有 Manus 原型：https://clientops-hybuephs.manus.space
- 标题：客户到期工作台 · 测试版
- 能力雏形：到期与到账核对、按日期/优先级筛选、虚构演练客户
- 问题：挂在 `*.manus.space` 预览域，不适合正式长期使用；需迁到可维护代码仓库

## 目标用户
中国商业银行 / 财富管理条线的**理财经理**（一对多客户维护）：到期提醒、续期跟进、合规话术、到账核对。

## 成功标准
1. 本地可 `npm run dev` 跑起中文 UI
2. 演示数据与「真实数据」模式分离（默认演示）
3. 至少实现下方「核心 + 亮点」功能，界面有专业感（深色/银行青绿皆可，干净现代）
4. README 写清如何跑、如何换数据源（先用本地 JSON/SQLite，预留 Notion API 接口注释）
5. 合规：不提供投资建议；所有外联话术带风险提示模板；操作留简单审计日志

## 核心功能（必须有）
1. **到期看板**：今日 / 7日内 / 已逾期 / 本月；筛选产品类型、优先级
2. **客户卡片**：姓名（可脱敏）、产品、到期日、保单/合同号、状态、最近跟进
3. **到期×到账核对**：到期应办事项 vs 到账/回执状态，差异高亮
4. **跟进清单**：一键生成今日待办；标记已联系 / 待回访 / 已办结

## 亮点功能（要出彩、有特点）
1. **续期作战室（Renewal War Room）**：单个到期客户一页：关键日期时间线、缺口清单、建议下一步（动作级，不荐产品）、合规检查勾选
2. **合规话术抽屉**：按场景（到期提醒、到账核对、犹豫期回访）给出**可复制**话术；每条带「不得承诺收益」提示；可一键复制
3. **优先级引擎**：按「距到期天数 × 金额档 × 是否逾期 × 是否高净值标签」打分排序，解释为什么排第一
4. **演练模式**：公开虚构客户 vs 授权快照分离（延续原型设计）；切换开关明显
5. **晨会简报**：一键导出今日「该打谁、为什么、说什么」Markdown/打印友好页
6. **审计轨迹**：谁在何时改了状态（本地演示用假用户「理财经理·演示」）

## 技术建议（可调整，选务实的）
- Next.js (App Router) + TypeScript + Tailwind
- 数据：先 `data/demo-clients.json` + 简单 API routes；SQLite 可选
- 中文 UI；移动端可用（理财经理常在手机上看）
- 部署：说明可部署到 Vercel；不要硬绑 Manus

## 不要做
- 不要真的接入支付/证券交易
- 不要编造真实客户数据；演示用明显虚构姓名
- 不要输出具体产品推销或收益承诺
